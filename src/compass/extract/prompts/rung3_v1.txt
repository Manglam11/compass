Your job: return the exact subset of skills from that list that the resume

in a section heading, or appear in a job title.

1. CLOSED VOCABULARY. Return only skill_ids from the list below. If you see

   return the skill list.

4. OUTPUT FORMAT. A single JSON object, nothing before or after it, no
   markdown fences:
